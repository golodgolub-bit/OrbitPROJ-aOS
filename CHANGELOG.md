# Changelog

## 0.4.0 preview / 2026-10-23

iOS navigation, interactive back driver, large-title collapse, tab controller and modal sheet detents. Shared glass DOM identities with matched geometry/materialize operations. Incremental scene add/remove and fixed scale restoration after dematerialization. English/Russian API guides.

## 0.3.0 preview / 2026-10-23

OrbitPROJ. / aOS by @qqDUCK. Root API now exposes semantic appearance,
menu/submenu controllers, window chrome, Dock/panel bindings and cancellable
Genie/Scale window transitions. Genie uses a texture mesh with Canvas 2D fallback.
Standard materials are separate from Liquid Glass Regular/Clear. Root imports
do not load the optical renderer. Legacy controls use a separate entry point.
No passive pointer lighting in the primary API; clock/thick optical presets removed.
macOS Tahoe 26 reference audit, bilingual integration/API documentation and
GitHub README screenshots/GIF. Windows host compilation and 33 automated tests.
See docs/validation.md for the limits of these checks.

## 0.2.0 preview / 2026-10-22

Initial independent glass UI toolkit. Materials, standard HTML control styling,
pointer lighting, bounded drag and spring return, keyboard tabs, in-app dock,
DOM contraction and canvas ribbon animation. English/Russian guides and demo.
Windows WebView2 and Android WebView host source. No Apple asset redistribution
or exact parity claim. See docs/coverage.md and docs/validation.md.
