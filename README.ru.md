# OrbitPROJ.

### aOS by @qqDUCK

Библиотека оформления, меню и анимаций окон для приложений **Windows, Android и Web**.

![OrbitPROJ. / aOS by @qqDUCK — окно приложения и строка меню](assets/menus.png)

[English](README.md) · [Подключение](docs/guide.ru.md) · [API](docs/api.ru.md) · [Эталон и точность](docs/reference.ru.md)

Материалы и поведение подключаются к разметке приложения. Команды меню, навигация и состояние остаются в коде разработчика. Liquid Glass — отдельный необязательный модуль наряду с обычными материалами, оформлением окон, меню и Dock.

| Модуль        | Возможности                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Оформление    | Стандартные материалы; CSS-приближение Regular/Clear; светлая/тёмная тема; контраст по явно заданному фону; вложенные радиусы; края прокрутки |
| Строка меню   | Открытие, переключение, подменю, недоступные команды, поиск по буквам, стрелки, возврат фокуса                                                |
| Окно          | Обработчики закрытия/сворачивания/масштабирования и события перетаскивания заголовка                                                          |
| Анимации окна | Сетка Genie и Scale, сворачивание/восстановление, цель снизу/слева/справа, отмена, уменьшение движения                                        |
| Dock и панели | Активация, увеличение по явной настройке, немодальные панели у якоря                                                                          |
| Оптика        | Преломление, общее кэшированное размытие, объединение SDF, маски, морфинг, появление материала                                                |

Основной API предоставляет оформление и контроллеры. Приложение задаёт семантические элементы, команды и состояние.

## Подключение

Пакет ещё не опубликован в npm. Установите из репозитория:

```sh
npm install github:golodgolub-bit/OrbitPROJ-aOS#main
```

Либо скачайте [устанавливаемый пакет](releases/qqduck-aos-0.4.0.tgz) и подключите локально:

```sh
npm install ./qqduck-aos-0.4.0.tgz
```

```js
import { createAppearance, bindMenuBar } from "@qqduck/aos";
import "@qqduck/aos/styles.css";

const appearance = createAppearance({ root: appRoot });
appearance.surface(yourSidebar, {
  family: "standard",
  variant: "thin",
  size: "large",
});
const menus = bindMenuBar(yourMenuBar, {
  onCommand: ({ id }) => dispatchCommand(id),
});

// При размонтировании:
menus.dispose();
appearance.dispose();
```

Разметка меню использует `aria-controls`, `role="menu"`, `role="menuitem"` и `data-command`. [Полный пример](examples/vanilla/index.html), [React](examples/react/Appearance.tsx), [контракт снимка окна](docs/api.ru.md).

Оптический рендерер импортируется отдельно:

```js
import { createGlassScene } from "@qqduck/aos/scene";
const scene = createGlassScene(canvas, yourBackdrop, { material: "regular" });
```

Приложение передаёт пиксели фона и геометрию. [API материала](docs/material.ru.md), [производительность](docs/performance.md).

## Запуск и встраивание

```sh
npm run demo
```

Откройте **http://127.0.0.1:4173**. В Windows можно запустить `Start-demo.cmd`. Установка зависимостей для просмотра примера не нужна.

| Платформа | Подключение                                    | Проверка                                                 |
| --------- | ---------------------------------------------- | -------------------------------------------------------- |
| Windows   | Исходники WPF / WebView2                       | Release компилируется; запуск на устройствах не проверен |
| Android   | Java / WebViewAssetLoader                      | Debug APK собран в GitHub CI; устройства не проверены          |
| Web       | ES-модули, CSS, необязательный WebGL2          | Автоматические проверки Chromium                         |
| React     | Привязка после mount, освобождение при unmount | Пример с типами                                          |

[Windows и Android — русский](docs/guide.ru.md) · [English](docs/guide.en.md)

Интерфейс работает внутри приложения. Реальное сворачивание окна в панели задач Windows и переходы Android Launcher контролирует ОС. Нативные рендереры Compose/WinUI не включены.

## Эталон и состояние

Профили — **macOS Tahoe 26 и отдельные паттерны iOS 26**, по открытой документации Apple. Меню, поведение окон и материалы разделены на модули. Численные размеры, оптика и кривые движения приблизительные. Системные службы, полный набор контролов Apple, все экраны iOS и закрытые эффекты не реализованы. [Покрытие](docs/coverage.md) перечисляет границы по функциям.
