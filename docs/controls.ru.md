# Справочник API

Все функции экспортируются из `@qqduck/aos`, стили отдельно из `@qqduck/aos/controls.css`. Типы находятся в `src/index.d.ts`.

| Функция                                                | Поведение                                                                                                                                                            |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `enhance(root = document)`                             | Подключает блики, перетаскивание, док и вкладки к существующей разметке. Возвращает `dispose()`. Не дублирует обработчики элемента/функции и не наблюдает новые узлы |
| `configure({root, quality, theme, transparency})`      | Устанавливает data-атрибуты. По умолчанию documentElement, balanced, auto, auto. Неизвестное значение вызывает RangeError                                            |
| `capabilities()`                                       | Возвращает `{backdrop, reducedMotion, popover}` по фактической поддержке функций                                                                                     |
| `animateSpring(update, options)`                       | Обновляет скалярное значение. Возвращает `{cancel, finished}`. Promise даёт true после завершения, false после отмены. Возможен выход за целевое значение            |
| `springState(time, from, to, options)`                 | Чистая аналитическая модель положения/скорости для трёх режимов затухания. Время в секундах, расстояния в CSS-пикселях                                               |
| `minimizeTo(source, target, options)`                  | Promise асинхронной функции восстановления. Равномерно сжимает DOM, скрывает source, включает inert и переводит фокус на target. Восстановление однократное          |
| `ribbonTo(snapshot, sourceRect, targetRect, options)`  | Promise<void>. Рисует полосы снимка canvas, после удаляет временный слой. Видимость исходного элемента меняет вызывающий код                                         |
| `ribbonRows(sourceRect, targetRect, progress, slices)` | Чистая геометрия. Координаты относительно viewport в CSS-пикселях. Progress 0..1, число полос 4..96                                                                  |
| `toast(message, {duration=3200, root=document.body})`  | Текстовое уведомление role=status. Возвращает функцию закрытия. Рекомендуется одно уведомление одновременно                                                          |
| `clamp(value,min,max)`, `lerp(a,b,t)`                  | Скалярные вспомогательные функции                                                                                                                                    |

Параметры пружины: `from:0, to:1, stiffness:240, damping:26, mass:1, velocity:0, epsilon:.001, maxDuration:2`. После достижения точности или maxDuration устанавливается точное конечное значение. `reducedMotion` по умолчанию читается из media query и сразу завершает движение. Жёсткость, затухание и масса должны быть конечными положительными числами. Callback `update` не должен выбрасывать исключения.

Сворачивание: `duration:540` мс, `reducedMotion` из системы. Лента: `duration:680`, `slices:32`, `reverse:false`, `reducedMotion` из системы. При уменьшении движения анимация пропускается. Последовательностью асинхронных эффектов и удалением сцены управляет приложение. Снимок должен быть уже загружен. Ограничивайте его размер и учитывайте ограничения cross-origin.

## Разметка

| Разметка                                 | Назначение                                                                                                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `class="aos-button" data-aos`            | Материал кнопки и блик. Используйте настоящий button или ссылку                                                                                         |
| `class="aos-surface aos-clear" data-aos` | Прозрачная поверхность. Другие варианты: aos-thick, aos-tinted                                                                                          |
| `data-aos-drag="return"`                 | Перетаскивание внутри родителя с возвратом. `free` сохраняет позицию                                                                                    |
| `data-drag-handle`                       | Область захвата с pointer capture, стрелками/Home. Укажите tabindex, роль и подпись                                                                     |
| `data-aos-tabs`                          | Контейнер role=tablist, кнопки role=tab. Нужны ID, aria-controls, aria-selected и связанные role=tabpanel. Поддерживаются RTL и вертикальная ориентация |
| `data-aos-dock`                          | Увеличение дочерних кнопок/ссылок под мышью. Для касаний увеличения нет                                                                                 |
| `.aos-switch input[type=checkbox]`       | Стандартный checkbox с оформлением. Нужна подпись                                                                                                       |
| `.aos-range`                             | Стандартный range. Укажите min/max/value и подпись                                                                                                      |
| `.aos-segmented`                         | Radio и следующий за ним span внутри label. Общее имя группы и доступная подпись обязательны                                                            |
| `.aos-dialog.aos-sheet`                  | Оформление dialog. Открывайте showModal(), закрывайте form method=dialog                                                                                |
| `.aos-menu[popover]`                     | Оформление popover. Проверяйте поддержку showPopover/hidePopover                                                                                        |

Перетаскивание отправляет всплывающее событие `aos:dragend` с `{x,y}` — координатами отпускания до завершения возврата. Другие контролы используют стандартные `click`, `input`, `change`. Библиотека не сохраняет настройки и не вызывает сеть или нативные API.
