Меню примера следует структуре приложения macOS. Список модулей, бренд и подменю Appearance — содержимое этого приложения, а не команды Finder. Control Center/Notification Center — дополнительные макеты без системных служб. Основная запрошенная область — строка меню и раскрывающиеся меню.

## Что не является измеренными константами Apple

Высота строки 28px, радиусы меню 12px/окна 14px, время сворачивания 620ms, параметры пружин, порог яркости, прозрачности, показатель преломления и деформация — значения этой реализации. Их точность не установлена сравнением на одном устройстве. API позволяет калибровать геометрию и оптику под известный эталон. Называть текущий пакет полной либо пиксельно точной копией Apple нельзя.

## Пробелы

Не реализованы полный набор экранов/навигации iOS, распространение SF/SF Symbols, системные службы, Mission Control/Stage Manager, управление full screen/tiling, системный композитор нескольких окон, живой захват нативного фона, HDR/wide color, автоматический движок сравнения layout и проверка всех устройств/браузеров/скринридеров. Сворачивание окна не равно закрытию вкладки браузера. [Покрытие](coverage.md), [проверки](validation.md).

Пользовательские референсы остаются локально и в архив не входят. Картинки репозитория показывают эту реализацию.
