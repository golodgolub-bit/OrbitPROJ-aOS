# OrbitPROJ. / aOS by @qqDUCK — выпуски

Репозиторий: [golodgolub-bit/OrbitPROJ-aOS](https://github.com/golodgolub-bit/OrbitPROJ-aOS). Пакет в реестре npm не опубликован.

## Подключение

```sh
npm install github:golodgolub-bit/OrbitPROJ-aOS#main
```

Ветка main меняется. Для воспроизводимости подставьте конкретный SHA коммита. Можно скачать [пакет 0.4.0](../releases/qqduck-aos-0.4.0.tgz) и установить через `npm install ./qqduck-aos-0.4.0.tgz`. В нём исходники, типы, документация, примеры и локальное демо, без нативных оболочек и инструментов разработки.

## Следующие выпуски владельца

Выполните `npm ci`, `npx playwright install chromium`, `npm run check` и проверки оболочек из guide.ru.md. Обновляйте версии пакета, оболочек и документацию вместе. `npm pack` создаёт устанавливаемый архив; проверьте его в чистом проекте перед добавлением в репозиторий. Снимайте медиа README с текущего приложения. Сгенерированные сборки и учётные данные не должны попадать в исходники.

CI проверяет Web и компилирует Windows/Android. Успешная компиляция отдельно от проверки запуска, доступности и физических устройств. Фактические результаты перечислены в validation.md.

Перед публикацией в реестре npm издатель должен владеть scope @qqduck. Войдите в свой аккаунт npm перед `npm publish --access public`. Токена реестра в проекте нет, публикация npm не выполняется.

Подпись приложений Windows/Android, актуальные требования магазинов, инсталляторы и устройства проверяются при выпуске приложения-хоста. Инструкции и оболочки: [guide.ru.md](guide.ru.md).
